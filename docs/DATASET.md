# RDD2022 source and data statement

Verified on 2026-11-05/06 (Africa/Cairo).

## Authoritative sources

- CRDDC2022 data page: <https://crddc2022.sekilab.global/data/>
- Maintainer repository: <https://github.com/sekilab/RoadDamageDetector>
- Author-published Figshare record: <https://doi.org/10.6084/m9.figshare.21431547>
- Dataset paper: Arya et al., “RDD2022: A multi-national image dataset for automatic road damage detection,” *Geoscience Data Journal* 11(4), 846–862 (2024).

The Figshare package reports **47,420 images** and more than **55,000 damage instances**. The challenge page gives approximate country counts totaling 41,500 annotated training images and 6,000 unannotated challenge-test images. The 80-image difference is why this project labels the challenge table as approximate and uses measured package/audit counts for experiments.

| Country | Approx. annotated training | Challenge test | Domain note |
|---|---:|---:|---|
| India | 9,000 | 1,000 | Vehicle/smartphone road view |
| Japan | 10,000 | 1,000 | Vehicle/smartphone road view |
| Czech Republic | 2,000 | 1,000 | Vehicle/smartphone road view |
| Norway | 9,000 | 1,000 | Vehicle-mounted, parallel to road surface |
| United States | 5,000 | 1,000 | Vehicle-mounted, parallel to road surface |
| China | 3,500 | 1,000 | Drone/handheld top-down or oblique imagery |

The official challenge test annotations are not public. RoadGuard therefore builds a deterministic held-out test split only from publicly annotated training material; it does not describe this custom test split as the official challenge benchmark.

## Taxonomy and format

| Class ID | Official code | Meaning |
|---:|---|---|
| 0 | D00 | Longitudinal Crack |
| 1 | D10 | Transverse Crack |
| 2 | D20 | Alligator Crack |
| 3 | D40 | Pothole |

The author package supplies JPEG images and Pascal VOC XML annotations for training data. YOLO labels generated by this project use `class_id x_center y_center width height`, normalized to `[0, 1]`. Other RDD annotation categories are deliberately ignored because CRDDC2022 evaluates the four classes above.

## License and redistribution

The maintainer GitHub README states CC BY-SA 4.0 for dataset images, while the author-published Figshare record displays CC BY 4.0. This project takes the conservative route:

- Raw images and annotations are never committed or redistributed.
- Dataset use is attributed to the authors and DOI.
- Example media is not published until its individual redistribution status is verified.
- The public code is AGPL-3.0-only because it integrates Ultralytics.

The official Figshare ZIP is 13,264,172,619 bytes with MD5 `b62bd51d2ffcfaa76c60f234f0cc2bb3`. The guarded downloader requires 40 GiB free before extraction. Kaggle training may use a public mirror strictly as transport; the kernel records the mirror ID, validates labels, excludes the mirror test folder because it mixes public labels with the unannotated challenge test, and reconstructs its own split.

## Split and leakage policy

- Fixed seed: 42.
- Country-balanced subset when full training is constrained by free GPU/runtime limits.
- Adjacent numeric frames (buckets of ten) stay in one split.
- Exact SHA-256 duplicates inherit one common split group.
- Country and class distributions are recorded in the frozen manifest.
- Route/location identifiers are unavailable, so complete geographic independence is **not** claimed.
- The held-out test split is not used for tuning or production model selection.
